# ApkStart 0.5.8 en español

Traducción al español de [ApkStart](https://github.com/RoutineMiku/apkstart) (licencia MIT, autor RoutineMiku).

- `app-es.zip`: la carpeta `resources/app` de ApkStart 0.5.8 con la interfaz traducida.
- `installer.nsi`: script NSIS del instalador en español.
- `.github/workflows/apkstart-es.yml`: descarga el instalador original, aplica la traducción,
  compila `ApkStart-0.5.8-Setup-es.exe` y lo publica en *Releases*.

Descarga el instalador desde la pestaña **Releases** del repositorio.
