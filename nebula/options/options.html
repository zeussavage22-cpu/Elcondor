Perfiles guardados

Guarda tu configuración actual (modo, dispositivo, región, protecciones) como una identidad con nombre y cámbiala con un clic.

General

«Mimetizar» reduce tu entropía pareciéndote a la mayoría. «Aleatorio» cambia tu identidad para que no te sigan entre sesiones.

Define de qué región salen la zona horaria y el idioma, siempre emparejados de forma coherente (p. ej. es-419 con America/Bogotá).

Elegir un dispositivo activa automáticamente el modo «Mimetizar».

«Estable por sesión» (recomendado): la huella es coherente dentro de la sesión y distinta por sitio, así no pareces un bot; cambia cada vez que regeneras identidad. «Por lectura»: cambia en cada medición — herramientas como Cover Your Tracks lo reconocen como «aleatorizada», pero un sistema antifraude puede notar el cambio continuo.

«Según mi IP» ajusta la zona a la geolocalización de tu IP actual (o la de tu VPN/proxy) para que concuerde con lo que ven los sitios y no salten alertas antifraude. Hace una consulta a un servicio de geo-IP solo cuando está activo.

Protecciones individuales

Perfil nuevo limpio

Qué se borra al pulsar «Crear perfil nuevo y limpio» en el popup (además de generar una identidad nueva). El historial, las contraseñas y las descargas NO se tocan.

Lista blanca de sitios

Un dominio por línea. Nébula se desactiva por completo en estos sitios (útil para bancos o sitios que rompan). Ej.: mibanco.com

Perfil personalizado (avanzado)

Editar en JSON. Se usa cuando el modo es «Perfil personalizado». Botón para precargar desde el preset actual.

Asistente con IA (opcional)

Sugiere el mejor perfil para cada sitio usando tu propia API key. Está apagado por defecto. ⚠️ Al usarlo se envía el dominio del sitio actual y el User-Agent real de tu navegador al proveedor de IA que elijas. No lo actives si no quieres esa consulta de red. Nunca ayuda a evadir antifraude.

Se guarda solo en tu dispositivo (storage local). Solo se usa para consultar al proveedor que elijas.

Déjalo vacío para el modelo por defecto del proveedor.
